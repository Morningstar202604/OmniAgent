万物皆可插件的
通用智能体

一个底座，N 种职业。不装插件，它是开箱即用的通用全能 Agent； 装上某个插件，同一个 Agent 立刻变成那个垂直领域的专业应用； 卸下插件，立刻回归通用——通用能力永远不被削弱。

快速开始 浏览源码 git clone
oa — omniagent cli
$oa --profile web "帮我看看这个行业报告"
→ 通用底座运行中：搜索 · 推理 · 写报告 · 导出 PDF
$oa plugin install dsh-finance
✔ 插件已加载，界面切换为金融终端
$oa --profile finance "回测贵州茅台双均线策略"
→ 行情 · 研报 · 回测 · 量化代码 · PDF 报告
$oa plugin uninstall dsh-finance
→ 回归通用底座，能力不被削弱

为什么是「万物皆可插件」

垂直领域工具层出不穷，却始终没有统一的解法。OmniAgent 把「通用底座」与「专业知识与工具」分离——底座负责思考与执行，插件负责专业与界面。

01 · 底座

通用全能 Agent

对话、搜索、写代码、操作文件、管理任务、长期记忆——日常能力全部内置并默认配好，开箱即用。

base · 永远在线
02 · 插件

加载即变专业应用

专业知识、专业工具、专业界面打包成插件。装上 dsh-finance，界面瞬间变成金融终端：行情、K 线、研报、回测一应俱全。

install · 界面瞬变
03 · 卸载

回归通用，能力不损

卸下插件，回到通用底座。专业能力随插件来去，通用能力永远完整——一个底座通吃所有领域。

uninstall · 来去自如

快速开始

克隆仓库，配置一个模型端点，即可使用。默认配置开箱即用，可高度自定义。

# 1. 克隆并安装（需要 Node ≥ 22.19 与 pnpm ≥ 11）
git clone https://gitcode.com/badhope/OmniAgent.git
cd OmniAgent && pnpm install

# 2. 配置模型端点（Agnes / DeepSeek / 任何 OpenAI 兼容端点）
export AGNES_API_KEY=your_key
export AGNES_BASE_URL=https://api.agnes-ai.cn/v1

# 3. 以通用底座启动
node apps/cli/lib/bin.js --profile web --no-open     # Web 界面 → http://127.0.0.1:3080

# 4. 加载金融插件，界面瞬变专业终端
node apps/cli/lib/bin.js --profile finance --no-open # 金融终端 → http://127.0.0.1:8631

# 5. 或直接用 CLI
node apps/cli/lib/bin.js --profile finance "回测贵州茅台的双均线策略并导出 PDF 报告"
