# @deepseek-ai/dsh-ecommerce — OmniAgent Ecommerce Operations Profile

A bundle of the general-purpose base plus the ecommerce operations plugin: enabling it injects the `ecommerce-agent` row (8 ecommerce tools + ecommerce persona) and the default model route into the current profile. Disabling it restores the general base.

- The Web sidebar **Plugins** page can toggle this bundle (official bundle, shipped off by default).
- CLI one-shot: `oa --profile ecommerce "<question>"`.

See [`ecommerce-agent`](../../ecommerce/ecommerce-agent/README.md).
