# @deepseek-ai/dsh-ecommerce — OmniAgent 电商运营专业 profile

通用全能底座 + 电商运营专业插件组合包：启用后向当前 profile 注入 `ecommerce-agent` 行（8 个电商工具 + 电商 persona）与默认模型路由。卸载/关闭即恢复通用底座。

- Web 侧栏「插件」页可启停本组合包（官方组合包，默认关闭）。
- CLI 一次性对话：`oa --profile ecommerce "<问题>"`。

详见 [`ecommerce-agent`](../../ecommerce/ecommerce-agent/README.zh.md)。
